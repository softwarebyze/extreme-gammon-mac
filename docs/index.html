Open source · macOS 14+

Play Extreme Gammon
on a Mac.

XG is a Windows program. This is a one-click wrapper so you can just play backgammon.

Download for Mac

Gets the latest release from GitHub.

How to install

  1. Download the zip. Unzip it.
  2. Double-click Extreme Gammon.
  3. If Mac says it cannot verify the developer, right-click the app, click Open, then Open again.
  4. First launch takes 5–10 minutes and needs internet. After that it just starts the game.

What you should know

The first launch downloads Wine and the official Extreme Gammon trial from extremegammon.com. We do not ship XG itself.

The trial is fully unlocked for 14 days. After that you buy a license from them if you want to keep it. This project is free and not affiliated with them.

Requirements

  • macOS 14 Sonoma or later
  • Apple Silicon or Intel
  • About 3 GB free
